# Code of Conduct

This is a small, single-maintainer project. The rules are short.

## Expected behavior

- Be civil. Disagree about code, not people.
- Assume good faith on the first round; ask before escalating.
- Stay on topic. Issues are for project work, not unrelated debate.
- If your comment doesn't help someone build something, reconsider posting it.

## Unacceptable behavior

- Harassment, threats, slurs, or personal attacks — in any space connected to this project (issues, PRs, discussions, commit messages, scaffolded repos).
- Sexually explicit or violent content.
- Doxxing or sharing others' private information without consent.
- Sustained disruption of discussions, repeated derailment, or bad-faith argument.

## Enforcement

The maintainer (currently `@rayketcham-lab`) is the sole arbiter. Actions, in escalation order:

1. Edit or hide the offending comment, with a brief explanation.
2. Warn the user.
3. Lock the thread.
4. Block the user from the repository.

There is no appeals process. This is a personal repository, not a community.

## Reporting

For anything that should not be public, use GitHub's private security advisory flow (`/security/advisories/new`) — it doubles as a private contact channel. Otherwise, open an issue.

## Scope

This applies to all spaces connected to this project. It does not apply to unrelated interactions outside the project's GitHub spaces.

## Inspiration

This document is intentionally short. It's inspired by the [Contributor Covenant](https://www.contributor-covenant.org/) but does not import it verbatim — for a single-maintainer project, a long covenant is performative.
